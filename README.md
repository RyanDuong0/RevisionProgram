Revision App
==========
Developed a fully functioning Windows Forms app using C# that helped GCSE and A-Level students revise more efficiently by eliminating the distractions that most websites have. 
I created a survey which was then distributed to both students and teachers to help me identify the features that were required. 
I was able to develop a backend database system using Microsoft Access and SQL to store accounts of the users, as well as, the subjects that each student is currently studying. 
In addition, I programmed an encryption module that hashed and salted user passwords, which were then stored in a separate database, to protect against data breaches. 
After this, I allowed students and teachers to test the program extensively so that I could gather their feedback and act upon it to improve the app for future users. I approached this app using a Rapid Application Development lifecyle as I created multiple prototypes of the app and tested it using pre-determined test data.
